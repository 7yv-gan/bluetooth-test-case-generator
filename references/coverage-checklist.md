# 企业级测试覆盖清单（蓝牙连接）

生成用例后逐项打勾核对，未覆盖的维度必须补充用例，保证交付的用例集完整可审计。

## 功能（FUN）
- [ ] 扫描/发现周边设备（含结果刷新、停止扫描）
- [ ] 设备可发现性开关（可被发现/不可被发现切换）
- [ ] 配对流程：各配对方式各一条正例
- [ ] 绑定与取消绑定（解除配对）
- [ ] 连接建立（正常路径）
- [ ] 断开：用户主动断开 / 对端断开
- [ ] 重连：自动重连 / 手动重连
- [ ] 数据传输：上行、下行、双向
- [ ] 多设备连接（若产品支持）
- [ ] 读取设备信息：名称、信号强度（RSSI）、电量、固件版本

## 边界（BND）
- [ ] 距离边界：正常距离 / 临界距离 / 超出范围
- [ ] 电量边界：设备低电量、主机低电量
- [ ] 连接数上限：达到上限后再连接新设备
- [ ] 超时边界：扫描超时、连接超时参数最小值
- [ ] 数据边界：单包最大长度、MTU 边界、超长数据包

## 异常（EXC）
- [ ] 蓝牙开关关闭状态下发起连接
- [ ] 飞行模式 / 勿扰模式
- [ ] 对端关机、断电
- [ ] 对端离开射频范围后恢复
- [ ] 连接/配对过程中用户中途取消
- [ ] 定位权限被拒绝（Android 扫描依赖）
- [ ] 系统重启、应用崩溃后状态恢复
- [ ] 强射频干扰环境（微波、其他 BLE 设备密集）

## 并发（CON）
- [ ] 多设备同时发起连接（竞态）
- [ ] 频繁连接-断开循环（压测）
- [ ] 连接建立过程中触发断开
- [ ] 多个应用同时访问蓝牙（系统级竞争）

## 兼容（COMP）
- [ ] Android 与 iOS 双平台各一条
- [ ] 新旧系统版本各一条
- [ ] 不同芯片方案：Nordic / TI / Realtek / Cypress / 高通
- [ ] 与其他蓝牙设备共存（耳机+鼠标+手环同时）

## 安全（SEC）
- [ ] 配对过程防中间人（MITM）：Numeric Comparison / Passkey 必须确认
- [ ] 数据传输加密（LE Secure Connections）
- [ ] 地址隐私：RPA 地址更新后重连
- [ ] 未授权设备尝试连接被拒绝

## 性能（PERF）
- [ ] 连接建立时延（冷启动连接 / 热连接）
- [ ] 扫描时延
- [ ] 数据传输吞吐（正常环境 / 弱信号环境）
- [ ] 长时间稳定运行（≥72h 不掉线）
- [ ] 功耗影响（连接后耗电增量）

## 体验（EXP）
- [ ] 连接状态 UI 反馈（连接中/已连接/失败）
- [ ] 失败提示文案清晰、可理解
- [ ] 断线后自动恢复的提示
- [ ] 无障碍：屏幕阅读器可读出连接状态
